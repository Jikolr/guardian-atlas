Guardian Atlas now includes the Lua implementations that were missing from the earlier export, alongside refreshed 3.55.0 data and artwork. This update makes many stage and system scripts readable in full while keeping existing source links usable.

What changed on the site

31 data tables refreshed · 785 additional Lua paths · one existing Lua source updated · 18 Unity bundles processed · 5,411 image previews or sprite crops written.

These are import counts. The 5,411 images include regenerated icons, and the 785 paths are not 785 confirmed new features.

From a loader to the actual implementation

Previously, a search could find a very short Lua file that named a controller without providing the controller's implementation. For example, AfterWorld1At1.lua contains the reference:

controller = 'stageeventcontrollers/AfterWorld1At1.lua'

The root file has three lines. The now-available controller contains 1,674 lines handling level loading, stage starts, area entry, interactions, scenes and a minigame. Both entries remain available: the root file explains the link, and the controller exposes the logic behind it.

The earlier inventory contained only one file inside stageeventcontrollers/; the new inventory contains 699. The new folder count includes one .etag companion file, which is a cache/version tag, not another Lua implementation. The imported source library now has 7,129 entries.

For 532 of the 785 additional paths, an unchanged root file in both versions already specifies the exact implementation path: 523 point into stageeventcontrollers/ and nine into worldexplore/. Three more have a same-named root file but a less direct path/syntax match. The remaining 250 have no same-named root entry in the old inventory. These three groups sum to 785.

What this means: much of the apparent increase is better capture coverage. Even the remaining 250 files cannot automatically be dated to 3.55.0; the earlier export may simply not have contained them. We are publishing newly available evidence, not announcing hundreds of new stages.

Existing links and the one changed shared source

Existing Lua entries retain their website IDs. New entries were appended, so an older link to a boss script still opens the same path. The import refreshed 786 sources in total: 785 additional paths plus the existing base/battle_init.lua.

That existing file adds an optional parent argument to the battle-state constructor. It initializes the new state's action, owner and C# action references when a parent is supplied. The v3.55 deep dive explains the actual diff and why it should not be presented as a confirmed damage buff.

The source chunks are now compressed for delivery, then decoded by your browser. You can still search and read the Lua normally, and the source viewer still downloads a readable file. This reduces hosting size without removing code.

The 31 refreshed tables cover heroes, actions, English text, equipment, awakening and character trees, buffs, projectiles, collections, events, raid scheduling and progression-related data. Astoria's profile brings together her four variants and linked equipment. The visual library includes her standard/Myth illustrations, character resources, item icons and additional Memorial Carp Girl assets.

The English table has 170,487 entries. Because many localization IDs moved, the curated biographies were rejoined by their exact text rather than blindly keeping the old numeric links. The identities wyverns_purple = Astoria and BridgeMessenger = Seira are explicitly confirmed by the site owner.

The artwork import processed 18 Unity bundles and wrote 5,411 previews or atlas crops with no extraction errors in that import. Most of these are refreshed sprites from shared sheets, not thousands of new designs. Existing maps remain available; the comparison found no map-file changes.

Downloads and version labels

Changed supported original game files have direct 3.55.0 downloads in Game files & downloads. The updated Lua is also available as readable individual files. Existing GitHub Release archives still contain the historical 3.54.0 snapshot and are labeled accordingly; they have not silently become 3.55.0 archives.

Website-export JSON sometimes wraps each record with an ID and a fields object. Those are convenient browsing exports, not claims that the encrypted original had exactly that layout. Local account settings and telemetry are excluded from the published file selection.

Newsletter is now the first category in the left sidebar. It will collect both game-file investigations and website updates. The former Game rules & code group is now Ingame datas; XP & progression and Reports & evidence no longer appear as navigation sections.
